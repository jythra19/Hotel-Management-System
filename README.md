# Hotel Management System

## About the Project
The Hotel Management System is a menu-driven Python application developed using Object-Oriented Programming (OOP) and MySQL. It helps manage hotel rooms, customer information, and bookings through a command-line interface.

## Features
- **Room Management:** Add, update, delete, search, and view available rooms.
- **Customer Management:** Add, update, delete, search, and view customer details.
- **Booking Management:** Create, update, search, and manage room bookings.
- **Checkout:** Process customer checkouts and update room availability.
- **Database Integration:** Store and manage data using MySQL.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- MySQL
- `mysql-connector-python`

## How to Run
1. Install Python and MySQL.
2. Install the required Python package:

   ```bash
   pip install mysql-connector-python
   ```

3. Make sure your MySQL server is running.
4. Run the application:

   ```bash
   python main.py
   ```

5. Enter your MySQL password when prompted.
